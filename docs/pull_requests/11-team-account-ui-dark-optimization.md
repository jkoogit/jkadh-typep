## 1. 작업 요약 (Summary)

사용자 인터페이스 거버넌스 원칙(정보 노출 빈도 기반 2계층 수납 및 시각적 노이즈 최소화)에 따라 **팀 계정 관리 화면(`TeamAccountManagerView.tsx`)의 UI/UX를 전면 최적화**하고, GitHub Dark 환경에 맞춘 **초슬림 다크 스크롤바 디자인 시스템(`src/index.css`)**을 구축하였습니다.

---

## 2. 주요 변경 내역 (Key Changes)

### 2.1 타겟 프로젝트 선택 영역 콤팩트 드롭다운화
- 기존 버튼 나열식 가로 탭을 콤팩트한 `<select>` 드롭다운 컴포넌트로 전환하여 헤더 공간 효율성 개선 및 레이아웃 정리.

### 2.2 역할(Role) & 허용 AI 모델 라벨(배지) 형태 복원
- **역할 컬럼**: 타겟 프로젝트에 매핑된 다중 RBAC 역할 배지 라벨(SUPER_ADMIN, ARCHITECT, ENGINEER 등)과 관리자 전용 `<Shield />` 아이콘 편집 버튼 복원.
- **AI 모델 컬럼**: 모델별 공식 테마 색상 라벨 배지(Claude 3.7, GPT-4o, Gemini 3.7 등)와 총 허용 개수 요약 노출 복원.

### 2.3 이름 영역 간소화 및 2계층 사용자 부가정보 팝업레이어 분리
- **테이블 행**: 불필요한 아바타 및 긴 이메일을 배제하고 **이름 + 소속 부서**로 시각적 간결성 유지.
- **상세 팝업 레이어**:
  - 이름 클릭 시 아바타, 이메일, 계정 식별자, 전역/프로젝트별 RBAC 다중 역할 배정 현황, 등록 AI 모델 목록, 토큰 쿼터/사용량, 거버넌스 감사 메타데이터 표시.
  - **헤더 & 푸터 고정**: 상단 프로필/기본 정보와 하단 닫기 버튼을 상시 고정(`shrink-0`).
  - **본문 독립 스크롤**: 세부 컨텐츠 영역에만 독립 세로 스크롤(`flex-1 overflow-y-auto`) 적용.

### 2.4 전역 및 모달 다크 테마 스크롤바 표준화 (`src/index.css`)
- **트랙 & 섬**: `#0D1117` 배경에 `#30363D` 슬레이트 그레이 섬 및 6px 초슬림 라운드 디자인 적용.
- **호버/액티브 인터랙션**: 마우스 오버 시 `#484F58`, 드래그 시 `#58A6FF` 블루 액센트 하이라이트.
- **모달 전용 스타일**: `.dark-custom-scrollbar` 클래스를 통해 팝업 내부에서도 시각적 이질감 없는 스크롤 UX 제공.

## 3. 3대 시나리오 검증 결과

- **정상 (Happy Path)**:
  - 타겟 프로젝트 드롭다운 전환 시 권한/쿼터 즉시 연동 검증
  - 사용자 행 클릭 시 상세 모달 오픈, 고정 헤더/푸터 및 본문 독립 스크롤 정상 작동 검증
- **오류 (Error Recovery)**:
  - 비관리자 접근 시 역할 및 모델 수정 버튼 차단 및 가이드 툴팁 제공 검증
- **예외 (Edge Bounds)**:
  - 프로젝트별 역할 미할당 시 플랫폼 전역 기본 역할 안전 Fallback 검증
  - TypeScript 컴파일 및 린트 (`tsc --noEmit`) 0건 무결점 통과
