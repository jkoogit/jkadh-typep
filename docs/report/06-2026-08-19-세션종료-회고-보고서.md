## 3. 금일 세션 주요 작업 내용 및 성과

### ① `[PDF-MERGE-06]` 무손실 바이너리 파서 및 XREF/Trailer 재구축기
- **파일**: `src/types/pdfMergeSplit.ts`, `src/services/PdfMergeSplitEngine.ts`
- **주요 기능**:
  - ISO 32000-1/2 표준 PDF 바이너리 파서 구현 (Header `%PDF-1.7`, Page Tree 탐색, Object 맵 추출)
  - 다중 PDF 병합 시 상호 참조 테이블(XREF) 오프셋 재계산 및 `startxref` 트레일러 포인터 재구축.

### ② 계층형 아웃라인/북마크 트리 전역 페이지 오프셋 리매핑 보존
- 입력 PDF별 고유 아웃라인(Outlines) 트리를 재귀 순회하여 각 문서의 시작 페이지 오프셋(`globalPageOffset`)을 자동 누적 가산 리매핑.
- 다중 문서 병합 후에도 3계층 Deep 북마크가 정확한 대상 페이지로 즉각 점프하도록 보존.

### ③ 페이지 범위 및 버스트 단일 페이지 무손실 분할기
- 콤마 및 하이픈 혼합 범위(`1-3, 5-8`) 정밀 파싱 및 1-based 인덱스 클램핑.
- `BURST_EACH_PAGE` 모드로 수백 장 분량 문서를 1페이지 단위의 독립 유효 PDF로 고속 분할.

### ④ 3대 시나리오 단위 테스트 및 3계층 Multi-Model Fallback
